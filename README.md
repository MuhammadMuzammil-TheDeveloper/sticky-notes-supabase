# 📝 Sticky Notes

A modern, responsive Sticky Notes application built with **HTML**, **CSS**, **JavaScript**, and **Supabase**.

Create, organize, and manage your notes with a beautiful UI, secure authentication, dark mode, and cloud storage.

## ✨ Features

* 📝 Create, edit & delete notes
* 🎨 Colorful note cards
* 🔍 Real-time search (`Ctrl + K`)
* 🌙 Light & Dark mode
* 🔐 Supabase Authentication
* ☁️ Cloud database storage
* 📱 Fully responsive design
* ⚡ Smooth animations & modern UI

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6+)
* Supabase
* Poppins Font

## 🚀 Getting Started

```bash
git clone https://github.com/MuhammadMuzammil-TheDeveloper/sticky-notes-supabase.git

cd sticky-notes-supabase
```

Add your Supabase credentials:

```javascript
const supabase = createClient(
  "YOUR_SUPABASE_URL",
  "YOUR_SUPABASE_ANON_KEY"
);
```

Run the project using **Live Server** or open `dashboard/dashboard.html`.
